Blantyre Road Network

Interactive Shortest Route Finder Using Dijkstra's Algorithm

This project represents selected locations in Blantyre City, Malawi, as an undirected weighted graph. Each edge represents an approximate road distance in kilometres. Select two locations to calculate and highlight the shortest route.

Find the Shortest Route

ReadyChoose a source and destination, then find the shortest path.

How Dijkstra's Algorithm Works

  1. Set the source distance to 0 and all other distances to infinity.
  2. Choose the unvisited location with the smallest tentative distance.
  3. Update the distances to its neighbouring locations when a shorter route is found.
  4. Repeat until the destination is reached or no reachable locations remain.
  5. Trace predecessor links to recover the shortest route.
