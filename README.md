# Blantyre Road Network — Dijkstra's Algorithm

A static browser-based demonstration of the assignment's weighted road network. It uses HTML, CSS, and JavaScript, so the lecturer can open it in a browser without installing a C++ compiler.

## Run locally
Open `index.html` in a modern browser.

## Publish using GitHub Pages
1. Create a GitHub repository (for example, `blantyre-road-network`).
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select the `main` branch and `/(root)`, then save.
6. Wait for GitHub Pages to publish, then open the generated URL.
7. Test the published page in a private/incognito browser window.

## Included graph
20 numbered locations and 26 undirected weighted edges, using the road-network data prepared for the assignment. Distances are assignment graph weights in kilometres, not live navigation data.
